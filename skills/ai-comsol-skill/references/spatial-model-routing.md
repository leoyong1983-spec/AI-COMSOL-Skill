# 几何分辨反应器模型的后续路线

V2已提供有来源假设下的二维/三维直流道基准，入口见[二维/三维说明](spatial-models.md)。已验证模式是充分发展层流速度PDE与物种/二次电流耦合；实际歧管/入口流场、传热、多孔电极内部及膜浓差仍需按以下路线扩展。没有本项目受控几何和完整传输/动力学时，保留工程假设和参数区间，不把基准模型称为实际装置复现。

## 物理接口选择

1. 有充分支持电解质且需解电极动力学：Secondary Current Distribution与中性底物/产物输运耦合；核对电解液电导率、对流、扩散、电极选择集及反应通量。若浓度/离子迁移显著影响电势，应改用适当的三级电流分布。
2. 稀溶液适用时：Tertiary Current Distribution, Nernst–Planck描述扩散、迁移、对流及电中性。不要在该接口已处理迁移/反应源项后再由另一接口重复添加。
3. 1M KOH等浓电解液：先核查活度、浓溶液传输和电导率适用性；“有Nernst–Planck接口”不代表稀溶液假设适用。
4. 多孔催化电极：提供孔隙率、曲折度、有效面积、渗透率、润湿/气含率及反应/输运边界；不能用几何面积替代比表面积而不换算电流。
5. 流动、热与膜：按实际流态、流道、接触热阻、焦耳/反应热及膜类型配置。气泡显著时再引入经验证的两相描述，不以普通水电解的气泡参数直接代替有机电解。

## 实施与校核

先用已有受控mph或最小几何验证接口、模块许可和真实实体选择。优先用几何特征生成的命名选择；不得照搬“边界1/3/2”等固定编号。检查每个反应面、进出口、绝缘面与膜侧的实体数、方向和实际对象。

先解流动，再逐步加入物种、电势和热耦合；延拓的是已声明参数，不悄悄删副反应或改物理边界。每层保存独立模型。以积分电流/总物质通量、元素/电荷、热量、网格/时间步敏感性和已知极限为校核；漂亮场图不替代定量闭合。

向0D/流程层只输出经验证的有效参数与适用区间：有效传质、局部最大电流密度、压降、穿梭通量、热负荷或反应源项。DSH组织任务与结果，不同时重复维护同一反应库存。
