# 乙二醇反应网络与0D模型

## 已纳入的碱性计量

以生成正、消耗负的计量系数记录真实离子和电子。下式只是反应网络模板，不表示所有反应在某一催化剂上都显著发生。

- 主候选：EG + 5OH- → GLY- + 4H2O + 4e-。
- C-C裂解：EG + 8OH- → 2HCOO- + 6H2O + 6e-。
- 深度氧化：EG + 10OH- → C2O4(2-) + 8H2O + 8e-。
- 析氧：4OH- → O2 + 2H2O + 4e-。
- 析氢：2H2O + 2e- → H2 + 2OH-。
- 可选有机阴极模板：糠醛 + 2H2O + 2e- → 糠醇 + 2OH-。该模板不是已冻结的本项目阴极路线。

其中EG为C2H6O2；GLY-为C2H3O3-。同分异构体不能用同一ID。若改为逐级EG—乙醇醛—乙醇酸根—乙醛酸根—草酸根网络，应重新列各步电子数、酸碱平衡和速率，不把并行终点模型与逐级模型同时套用而重复计电子。

## 物料与电流

对液体池p和物种i：

    Vp dc_i/dt = Qp(c_feed,i-c_i) + Σ_j ν_ij r_j + membrane_in,i - membrane_out,i
    r_j = I_side,j/(n_j F)
    Σ_j I_cathode,j = Σ_j I_anode,j = I_command

所有液体和气体累计量另设状态；用初始库存＋累计新鲜进料－累计流出/排出核查全元素守恒。单室共用电解液只设一份液体库存；双室分别设库存。流量Q指净进出，不是搅拌/循环流量。

给定FE模式中I_side,j=I_command×FE_side,j。要求两侧各自支路闭合；未归属电流须在资料中保留，不自动变成某一化学反应。为了进行完整情景衡算而作的支路假设必须随结果卡输出。

前向Tafel模式：

    j_j = j_ref,j × (c_sub/c_ref,j)^m × exp[alpha_eff,j F(eta_side-offset_j)/(RT)]

每侧通过代数方程求eta，使各支路面积积分电流等于同一个I_command。两侧面积可以不同。该式为受限前向经验支路；未实现可逆Butler–Volmer、传质平台、覆盖度机理或自动温度外推。alpha_eff需对应拟合表达式，不能自动按终点反应的n倍增。

## 膜与热

双室本版支持已明确的单价阴离子从阴极向阳极传递，每摩尔电子对应一摩尔载流离子；OH-为已测软件模板。中性穿梭按P_i A_mem(c_c,i-c_a,i)计算，P由来源提供，不能由体相扩散系数直接冒充。

没有解Donnan、电渗、局部浓度极化、膜水通量或双极膜水解离；这类用途须切换到空间模型。单室模式不引入虚构膜。

等温模型不计算温度演化。Tafel模式可在同一电极电势参考下给出Ucell=Eref,a-Eref,c+eta_a+eta_c+I Rcell；给定FE模式没有足够信息预测槽压。缺少统一反应焓和焓参考时Qheat为空。HYSYS/DWSIM焓值未统一参考前不能直接相减。

## 从模型到工程量

反应器出口盐形态不是分离后产品纯度。净消耗EG、生成GLY、H2、甲酸根和草酸根分别统计，转化率与选择性须声明单程、库存或累计口径；跨膜、排污和分离回收另记。

由小试电流放大时需明确串并联：串联单元电流相同，反应量累加，堆电压累加；并联支路电流相加。不能把堆总电流、单元数和面积重复相乘。未取得实际电堆构型和有效面积前，不将本版结果直接换算为工业电堆功率或产能设计值。
